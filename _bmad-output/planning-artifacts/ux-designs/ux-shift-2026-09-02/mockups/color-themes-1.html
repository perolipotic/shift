Shift — palette and shift-state encoding

Four palettes, each shown light and dark, using the pilot's real content: DVD Kaštel Novi, teams Smjena A–D, shift types Dan / Noć / Slobodno. Every string here also exercises Croatian diacritics — č ć ž š đ — so a typeface gap shows up immediately. Then three strategies for encoding state without relying on colour.

One finding worth deciding before you pick a palette. The PRD allows the pilot a fire-department red accent. The spec requires an unresolved conflict to be visible at a glance. If brand red and conflict red are the same red, conflicts stop reading as conflicts — the alarm colour becomes the furniture. Either the brand accent avoids red, or conflict stops being carried primarily by hue. Variation 2 takes the first route; the encoding strategies below take the second.
And a structural point that makes the seven-state problem tractable. The seven states aren't peers. Three are base states — the shift type, which is Organization data and can be any number of them. Four are modifiers — leave, conflict, uncovered, overridden — which are system-defined and fixed forever. So: let colour carry the base state (org data, unknown count), and let a non-colour signal carry every modifier (fixed set, designable once). That satisfies "must work for shift types the design never anticipated" instead of fighting it.

Typeface — the one hard constraint

Croatian needs Latin Extended-A. A face without it falls back mid-word, which looks broken in exactly the places that matter most — shift names, month names, member names.

Must renderWhere it appears
č ć ž š đ Č Ć Ž Š ĐNoć · Godišnji · Slobodno · Izmijenjeno · Kaštel · Lipotić
tabular numeralsthe hours table and every 07:00–19:00 — proportional digits make columns wobble

Safe with full coverage and tabular figures: Inter, Source Sans 3, IBM Plex Sans, Noto Sans. shadcn's default Geist also covers it. Your call — this is the one place I'd rather you named a preference than inherited mine.
