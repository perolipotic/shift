Rješavanje konflikta

The product's distinguishing stance made concrete. The spec requires that a collision is surfaced and handed to a human, that accepting an uncovered shift is a legitimate choice rather than a failure path, and that resolving must never be faster by being automatic. All three shape this screen.

Design rule this screen encodes. Each option states its consequence in the same three terms — coverage, the absent member's hours, the balance — so the admin compares outcomes rather than guessing them. There is no primary-styled "recommended" option and no bulk-resolve affordance anywhere, because either would make the automatic path the fast path.
