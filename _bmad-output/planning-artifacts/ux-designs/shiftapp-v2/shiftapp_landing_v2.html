Mobile PWA for workers

Workers install ShiftApp from a link — no App Store. Works on any phone, works offline. See schedule, clock in, request leave.

Leave & swap approvals

One-click approve or deny. Coverage check runs automatically. Everyone notified instantly via push notification.

Already have a Dormakaba, Spica, or Interflex terminal? We pull clock-in data automatically. Workers change nothing. You get real-time data.

Reports & overtime alerts

Attendance rates, overtime tracking, shift coverage. Export to CSV for any payroll system. Croatian and German labour law rules built in.

Croatian, English, German, Turkish, Polish. Each employee chooses their own language. No extra cost.
