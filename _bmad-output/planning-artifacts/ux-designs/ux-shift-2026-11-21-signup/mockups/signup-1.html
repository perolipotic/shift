3 · Jedan neutralan odgovor (UX-DR63, FR-99, AD-22)

The one screen after Registriraj se, identical for a new, a known confirmed and a known unconfirmed address, because the gateway answers 200 {} for all of them and the SPA never reads the body. The address shown is what the user typed (theirs, so it reveals nothing) with a way back to correct it. Pošalji ponovno is throttled on the page for 60 s (GOTRUE_SMTP_MAX_FREQUENCY); after a resend the same neutral sentence comes back as a status line. A 429 from Kong's per-IP limit is the one other answer: it says nothing was sent, which is about this network, never about the address.

4 · Nepotvrđena prijava i /potvrda (UX-DR63)

email_not_confirmed needs the right password, so a sign-in with it may say the address is unconfirmed and offer a new link; the resend then lands on screen 3. /potvrda?token_hash=…&type=signup verifies only when Potvrdi is pressed, never on load (a mail scanner consumes nothing, AD-22). Success goes straight to step 1 of /postavljanje with the status line Adresa je potvrđena., on whichever device opened the link. A used or expired link gets one neutral page; it cannot resend, because the token carries no address the page may name.
